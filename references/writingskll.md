# Report Writing Skill

## Purpose

Convert gathered research into a clear, professional Markdown report.

## Structure

Use the following structure when appropriate:

# [Report Title]

## Executive Summary

Brief summary of the most important findings.

## Key Findings

List the major findings.

## Detailed Analysis

Present the evidence and analysis.

## Data / Metrics

Use Markdown tables when numerical comparisons
are useful.

## Market / Competitive Context

Include relevant comparisons when requested.

## Risks and Limitations

Identify important limitations in the available data.

## Outlook

Discuss future implications only when supported
by available evidence.

## Sources

List the sources used in the research.

## Formatting Rules

- Use Markdown.
- Prefer tables for structured numerical information.
- Keep paragraphs concise.
- Do not repeat the same information.
- Clearly distinguish sourced facts from interpretation.
- Never fabricate statistics or sources.
